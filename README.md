# distance-calculator
## This program converts kilometers to miles


## How to Run
1. Open the program in Python or VS code.
2. Run the program
3. Input the values for kmd that you want to convert

## Input needed
- kmd (Kilometers)
- a (string)
- kmD (Kilometers)

- enter distance in kilometers: 10
